Was macht TankCopilot besonders?

  • Realistische Verbrauchsberechnung: Während andere Apps nur Volltankungen berücksichtigen, analysiert TankCopilot alle Tankvorgänge für präzise Ergebnisse.
  • Kostenoptimierung durch intelligente Tankstellenwahl: Nicht nur der Preis zählt – TankCopilot berücksichtigt auch die Fahrtkosten und zeigt Ihnen, ob sich die Fahrt wirklich lohnt.
  • Keine Cloud, keine Tracking-Daten: Ihre Daten gehören Ihnen. Alles wird lokal in Ihrem Browser gespeichert (IndexedDB). Keine Server, keine Analytics, keine Cookies.
  • PWA – kein App-Store nötig: Installieren Sie TankCopilot direkt aus dem Browser. Keine Wartezeiten, keine Store-Gebühren, sofort verfügbar.
  • DSGVO-konform von Grund auf: Datenexport, Datenlöschung, volle Kontrolle – alle DSGVO-Rechte sind integriert.

Installation – So einfach geht's

📱 iOS (iPhone/iPad)

  1. Öffnen Sie Safari und besuchen Sie fluvento.de/TankCopilot/app/
  2. Tippen Sie auf das Teilen-Symbol (Quadrat mit Pfeil nach oben)
  3. Wählen Sie "Zum Home-Bildschirm" aus dem Menü
  4. Bestätigen Sie mit "Hinzufügen"
  5. Die App erscheint jetzt auf Ihrem Home-Bildschirm und funktioniert wie eine native App

Hinweis: Die Installation funktioniert nur in Safari, nicht in Chrome oder anderen Browsern auf iOS.

🤖 Android

  1. Öffnen Sie Chrome (oder einen anderen modernen Browser) und besuchen Sie fluvento.de/TankCopilot/app/
  2. Tippen Sie auf das Menü-Symbol (drei Punkte oben rechts)
  3. Wählen Sie "Zum Startbildschirm hinzufügen" oder "App installieren"
  4. Bestätigen Sie die Installation im Popup
  5. Die App erscheint auf Ihrem Startbildschirm und kann wie eine native App genutzt werden

Hinweis: Auf manchen Android-Geräten müssen Sie möglicherweise die Installation von unbekannten Quellen erlauben.

💻 Desktop (Windows/Mac/Linux)

Öffnen Sie TankCopilot in Ihrem Browser. Die PWA funktioniert auch ohne Installation. Optional können Sie in Chrome/Edge über das Menü "App installieren" wählen.

Häufige Probleme & Lösungen

Standort wird nicht erkannt

Problem: Die App kann Ihren Standort nicht ermitteln.

Lösung:

  • Prüfen Sie die Standortberechtigungen in den Einstellungen der App
  • Auf iOS: Einstellungen → Safari → Standortdienste aktivieren
  • Auf Android: Einstellungen → Apps → TankCopilot → Berechtigungen → Standort erlauben
  • Stellen Sie sicher, dass GPS aktiviert ist
  • Versuchen Sie es im Freien für bessere GPS-Genauigkeit

App zeigt keine Tankstellen an

Problem: Die Tankstellensuche liefert keine Ergebnisse.

Lösung:

  • Prüfen Sie Ihre Internetverbindung
  • Warten Sie einige Sekunden – die API-Abfrage kann etwas dauern
  • Versuchen Sie, den Standort manuell einzugeben
  • Laden Sie die Seite neu (Strg+F5 / Cmd+Shift+R)

App aktualisiert sich nicht

Problem: Nach einem Update werden alte Versionen angezeigt.

Lösung:

  • Löschen Sie den Browser-Cache und Service Worker
  • Chrome/Edge: Einstellungen → Datenschutz → Browserdaten löschen → "Gecachte Bilder und Dateien"
  • Safari: Einstellungen → Safari → Verlauf und Websitedaten löschen
  • Laden Sie die Seite neu (Strg+F5 / Cmd+Shift+R)
  • Falls das nicht hilft: Deinstallieren und neu installieren

Installation funktioniert nicht (iOS)

Problem: "Zum Home-Bildschirm" erscheint nicht im Safari-Menü.

Lösung:

  • Stellen Sie sicher, dass Sie Safari verwenden (nicht Chrome oder Firefox)
  • Die Funktion ist nur in Safari verfügbar
  • Prüfen Sie, ob die Seite vollständig geladen ist
  • Versuchen Sie es in einem privaten Tab erneut

Installation funktioniert nicht (Android)

Problem: "Zum Startbildschirm hinzufügen" erscheint nicht.

Lösung:

  • Verwenden Sie Chrome oder einen anderen modernen Browser
  • Prüfen Sie, ob die Seite vollständig geladen ist
  • Manche Browser zeigen die Option erst nach mehrmaligem Besuch
  • Prüfen Sie die Browser-Einstellungen für PWA-Installation
